# 地图重设计（11-02，草案）

用户：「那么干脆从头设计地图吧，反正现在的也不是很满意」「和现在的数量一致」「（规则）基本上都保留」「素材我再想想办法」。
起因见 `docs/素材许可清单.md`：现有 8 张对战图的主体素材都不能商用。

## 原则

- **先玩法、后外观**：每张图先用引擎方块搭灰盒（不算手搓资源，和以前夺芯灰盒一样，只为试布局），能打、AI 能跑、数字对了再换素材。
- **不绑定素材包**：下面只写「需要哪几类东西、多大、多少件」。用户找到什么素材都能按类别套进去；同一类换一个包，布局不动。
- **规则全部保留**：飞行 + 落水（石林）、低重力 + 真空静音（月球）、无限循环（老街）、严寒（苏联）、夜雨（街道）、湖水损毁（荒野）、保卫战（梦核）。代码在 `MechMapRules`、`MechLoop`、`MechVacuum`、`MechWater`，换图不用改，只要新图带同样的标签（`WaterKill`、`OldStreetBounds`、`MoonAir` 等，见 README 各节）。
- **尺度**：机体约 2.5 米高，冲刺 / 喷射很快。现有图里手感对的尺度沿用：近战图 100–220 米见方，中距离 220–300 米，空战 / 开阔 600 米以上。头顶封顶按「喷射到顶不至于飞出画面」定。
- **每张图都要有**：两队出生区互相看不见（`TeamSpawn0/1`）；死斗 8–12 个重生点（`DMSpawn`）；至少三条进攻路线（地面 / 高处 / 绕后），每条都有掩体；一个明显的「中心」；能在 3 秒内认出自己在哪（地标）。
- **团队淘汰的图左右（或中心）对称**；只有死斗的图可以不对称。

## 八张图

### 1. 赛博朋克街道（L_Street，默认图，团队淘汰 / 死斗）
- **定位**：近距离、垂直。夜晚小雨，霓虹。
- **布局**（约 180 × 140 米，封顶 45 米）：一条主街 + 两层高架（6 米、14 米）+ 街两侧可进的商铺底层；中间一座过街天桥是中心。两队出生在主街两端的封闭广场。绕后路线走后巷和屋顶。
- **保留**：夜雨天气、空气墙防坠落（11-02 玩家建议 7）。
- **素材**：沿街楼 8–12 栋（底层能进）、高架桥段 / 坡道、招牌 / 霓虹灯箱、车辆 6–10、路障 / 集装箱等掩体 20+、雨天湿路面材质。

### 2. 荒野与废墟（L_Nature，团队淘汰 / 死斗）
- **定位**：中远距离，地形起伏 + 废墟掩体。白天。
- **布局**（约 300 × 300 米）：中间一个湖（落水损毁，岸边浅水没事），湖两侧各一片废墟；北面高地上一座塔（彩蛋压力板在塔顶）。两队出生在东西两端的林地。
- **保留**：湖水损毁、塔顶彩蛋。
- **素材**：地形（自己用 Landscape 刷，贴图用 CC0 地表）、树 5–8 种、灌木 / 草、岩石 6–10、废墟建筑 4–6 栋、塔 1、自然环境音。

### 3. 相位电子园区（L_TechPark，团队淘汰 / 死斗）
- **定位**：中距离、企业制式（干净白色、切角、青色点缀，见世界观）。阴天下午。
- **布局**（约 220 × 160 米，封顶 42 米，左右镜像）：中央广场 + 一圈 7.5 米高架环路；南北各一座安检门进出基地；总部塔是地标。
- **素材**：科幻模块化建筑一套（墙、柱、门、平台、坡道）、全息屏 / 标牌、长椅 / 路灯等小品、玻璃材质。PHASE 标识已经是自己的 SVG。

### 4. 梦核旷野（L_Dreamfield，保卫战 + 团队淘汰 / 死斗）
- **定位**：开阔、超现实。亮黄绿草坪、粉蓝天空、大行星；一面 200 米高的巨构墙。
- **布局**（X ±300、Y ±450，封顶 130 米）：墙脚 24 米高的二级平台（堡垒）、两部电梯、两头坡道；旷野上几座矮丘。保卫战的波次刷怪点不变。
- **保留**：保卫战规则；天空（CC0）、草和花（Fab 免费）已经能商用，**只换巨构墙、云、行星贴图**。
- **素材**：巨构墙（大尺度模块或用简单几何 + 好材质）、云（Niagara / 体积云）、行星贴图（NASA 公有领域图就行）。

### 5. 石柱山水 / 石林（L_Pillars，团队淘汰 / 死斗，空战）
- **定位**：空战。水上石林，掉水就毁。
- **布局**（约 800 × 620 米）：30–50 根 70–110 米高的石柱，中间稀、外圈密；三四座连成片的「岛」可以落脚回能；两队出生在两端的大岛上。石柱间留出俯冲通道和绕柱路线。
- **保留**：飞行、空中回能 ×1.7、固定推进器、落水损毁、AI 不落水、「PULL UP」提示。
- **素材**：岩柱 6–10 种（可以缩放复用）、岩石材质 + 苔藓、水面（引擎 Water 插件就行）、远景山、云海 / 雾。

### 6. 苏联板楼（L_Soviet，团队淘汰 / 死斗，枪械主场）
- **定位**：长视线、枪战。冬天、阴天下雪。
- **布局**（约 300 × 220 米，限高 62 米，中心对称）：两条 300 米东西长街 + 两条横街；三个大院（两队出生广场 + 中院）；后巷绕后。居民区里没有工业烟囱，楼沿街排（11-02 用户意见）。
- **保留**：严寒规则（枪过热慢、回能慢）、中院的友好机械狗彩蛋（滑梯 / 跷跷板这些游乐设施要有）。
- **素材**：板式住宅楼 3–5 种（5 层 / 9 层 / 16 层）、院子小品（游乐设施、长椅、垃圾箱、车）、积雪材质、下雪特效。

### 7. 月球基地（L_Moon，团队淘汰 / 死斗）
- **定位**：低重力，跳得高、落得慢；穹顶外真空，远处声音听不见。
- **布局**：NASA 真实地形保留（公有领域，月壤 CC0），只换基地。东西两队沿 X 对称；北边机库区（高、屋顶能走），南边储罐区（矮、开阔）；中间一座大穹顶（里面有空气）。
- **保留**：1/3 重力、真空静音（穹顶带 `MoonAir` 标签）、星空和地球。
- **素材**：月球基地舱体 / 穹顶 / 机库 / 储罐 / 太阳能板（NASA 3D Resources 有公有领域的舱体和着陆器可以参考或直接用）。

### 8. 老旧街道（L_OldStreet，死斗，无限循环）
- **定位**：娱乐图。一条看起来无限长的老街，其实只有 100 米一段，机体和子弹沿街循环。
- **布局**：沿街 100 米一周期、街宽 ±7.6 米（隐形墙）；两侧老楼底层商铺；一扇能打破的门（彩蛋，门要放在墙内侧）。
- **保留**：循环代码（`MechLoop`）、过接缝的镜头修正、只给前方最近敌人画威胁框、老街狗群彩蛋。
- **注意**：循环要求「所有周期完全一样」——楼、地面、树都要按 100 米整除排；不能有世界坐标的云影和风（见 README「老旧街道」）。
- **素材**：老式沿街楼 4–6 种（底层商铺）、路面 / 人行道 / 路缘、电线杆 / 电线、招牌、树 2–3 种。

### 训练场（L_Range）
UE 模板原型资源，不用换。

## 全局要换的（不分地图）
- **特效**：爆炸、命中、刀光、导弹尾焰、烟雾（现 `/Game/AAAVFX`）。
- **音效**：枪声、爆炸、脚步、推进器、界面；环境音。
- **武器模型**：步枪、冲锋枪、霰弹枪、狙击、充能步枪、手枪、各种刀 / 钝器（现 `/Game/Weapons`）。
- **背景音乐**：放进音乐包（`MusicPack`）就能换，不用重新打包。
- **待查**：机甲组件库（机体、肩部装备、彩蛋外壳都从它拼）。

## 顺序（建议）
1. 先定这份文档（用户改哪张、怎么改）。
2. 灰盒：一张一张用引擎方块搭，进游戏试打（AI 对战 + 手感），改到满意。
3. 素材到了按类别换上；每换完一张拍总览图对比。
4. 全局特效 / 音效 / 武器另起一轮。
