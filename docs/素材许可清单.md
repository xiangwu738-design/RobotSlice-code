# 素材许可清单（11-02）

用户：「我这里使用的有些资源是不是也可以购买？」「我打算做一轮去除不可商用素材」。
**这不是法律意见**：许可以每个素材的原发布页 / 许可证为准；「来源」按 README「素材来源」、各地图章节和用户 11-02 的回答（K 系列、F25、老旧街道.blend 都是网盘下载的）。

## 怎么得出来的

- `tools/ue_asset_audit.py`（kind=py，只读）：从会进包的东西出发——`DefaultGame.ini` 的 9 张 `MapsToCook` + `DirectoriesToAlwaysCook` 的目录——顺着硬 / 软引用找到 **3756 个包**，按来源文件夹归类。完整清单在用户电脑 `Saved/AssetAudit/audit.json`（包名 → 用到它的地图 / 目录）。
- `tools/grade_pack_ident.py` + `blender_pack_ident.py`：Blender 读 `Inbox` 里 21 个 K 开头的 .blend 的材质 / 贴图前缀。Kitbash3D 的命名是 `KB3D_<套装代号>_`。

## Kitbash3D 许可要点（买之前看）

- 许可档位按**购买时公司人数**定；个人 / 自由职业买个人档，两人以上的团队买对应的商业档，档位买低了许可无效。
- 官方帮助中心写明可以用于商业的电影、游戏、VR/AR。
- 不能以可编辑、可提取的形式再分发模型；打进游戏包里是正常用法，但建议买前问一下客服在游戏构建里怎么算（Fab 上这几套写的是「用于 UE5 影视」）。
- 链接：[许可页](https://kitbash3d.com/pages/licenses)、[帮助：商用](https://help.kitbash3d.com/en/articles/6449681-can-i-use-kitbash3d-assets-for-commercial-projects-or-for-nfts)。

## 建议的顺序

1. **背景音乐**：最容易换（音乐包已经做好，不用重新打包），也是最确定不能商用的。
2. **全局三样**：特效、音效、武器。所有图都用，换一次全部生效。
3. **查清待查的**：机甲组件库、`Env/Textures`、`Env/Canyon`、`VFXWeatherPack`、彩蛋两个底模。
4. **地图**：留哪几张进正式版、每张买还是换，逐张定。正式发布前定就行。
